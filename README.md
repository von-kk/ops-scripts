ops-scripts
日常运维中重复劳动的自动化脚本合集：把手工敲的命令变成可复用的工具。用 Python 标准库实现，不依赖第三方包。

脚本列表
脚本	作用	依赖
ping1.py	批量检测主机可达性，汇总通/不通数量	Python 3.6+、系统自带 ping
运行方式
准备 IP 列表文件 ips.txt，每行一个 IP：
Code block


127.0.0.1
223.5.5.5
114.114.114.114
执行：
bash


python3 ping1.py
输出示例
Code block


127.0.0.1 通
223.5.5.5 通
114.114.114.114 不通
192.168.99.99 不通
10.255.255.1 不通
通 2 个，不通 3 个
已知限制
用 ICMP 判断，会误报。 部分主机（如公共 DNS 114.114.114.114）服务正常但屏蔽 ICMP，会被误判为「不通」。更可靠的做法是检测 TCP 端口是否监听。
串行执行，主机多时慢。 每个不通的主机要等满超时（约 2 秒），100 台最坏要 200 秒。后续可用并发优化。
超时参数不跨平台。 -W 1000 在 macOS 上单位是毫秒，在 Linux 上是秒，换平台需改参数。
IP 列表写死在代码里。 目前不支持命令行传入文件路径。
